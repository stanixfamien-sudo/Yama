# 🌸 YAMA

> L'App de ma Best.

YAMA est un petit univers personnel qui évoluera autour des goûts, souvenirs, envies, humeurs et surprises de son utilisatrice.

## MVP
- 🏠 Accueil
- 👤 Profil et préférences
- 😊 Mood
- 📸 Souvenirs
- 🎁 Wishlist
- 💌 Surprises
- 🤖 Yama AI (phase suivante)

## Stack initiale
- React + TypeScript
- Vite
- Supabase
- Lucide React

## Développement
```bash
npm install
npm run dev
```

## Variables d'environnement
Copier `.env.example` vers `.env.local` et renseigner les valeurs locales.

**Ne jamais commit une clé secrète.**
